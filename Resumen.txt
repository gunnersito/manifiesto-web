1. ARQUITECTURA Y ENTORNO
- Backend: FastAPI + SQLAlchemy + SQLite (entregas.db). Usa Pandas y Openpyxl.
- Frontend: Next.js (React) con Tailwind CSS v4 y shadcn/ui (usando Base UI).
- Arranque: Usamos "concurrently" en la raíz (npm run dev) para levantar front y back en una sola terminal.
- IDE: WebStorm configurado correctamente con el intérprete .venv de Python.

2. PROBLEMAS RESUELTOS (Backend)
- Error 404 (Provincias): El frontend llamaba a /manifiestos/{id}/hbls pero el backend no lo tenía. Se creó la ruta @router.get("/{manifiesto_id}/hbls").
- Error 422 (Registros): El frontend llamaba a /hbls pero el backend exigía el ID. Se restauró el endpoint @router.get("/hbls") con el ID como opcional (Optional[int] = None).

3. PROBLEMAS RESUELTOS (Frontend)
- Dependencias: Se instalaron todas las librerías faltantes de Tailwind v4, shadcn, Base UI y CVA.
- Refactor de Provincias: Se eliminó la carpeta [nombre] y se unificó todo en src/app/provincias/page.tsx.
- URLs Limpias: Ahora la URL usa Query Params (ej. /provincias?nombre=PINAR%20DEL%20RIO) en lugar de rutas dinámicas con %20. La página decide si muestra el listado de tarjetas o el detalle basándose en si recibe el parámetro "nombre".
- Next.js 15: Se añadió "export const dynamic = 'force-dynamic';" para evitar errores con useSearchParams.

4. PENDIENTE PARA LA PRÓXIMA SESIÓN
